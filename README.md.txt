# Spartan Beast

Aplicación full stack para la gestión y presentación digital de Spartan Beast.

## Stack

### Backend
- Java 21
- Spring Boot 4
- Spring Data JPA
- PostgreSQL
- Flyway
- Spring Security
- JWT
- Swagger / OpenAPI
- JUnit
- Mockito
- MockMvc

### Frontend
- Angular
- TypeScript
- SCSS

> Frontend actualmente en desarrollo.
